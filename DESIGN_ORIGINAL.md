## Brand & Style

This design system embodies high-end luxury, meticulous event production, and celebratory grandeur. Created for celebratory management platforms, high-profile gala planning, and bespoke event orchestration, it reflects elegance, exclusivity, and warm hospitality. 

The aesthetic is built upon a hybrid of **Atmospheric Luxury & Warm Minimalist Clarity**:
- Deep obsidian and charcoal backdrops evoke intimate VIP ballroom ambiances and evening glamour.
- Rich rose gold, warm champagne, and burnished metallic copper provide luminous accents that celebrate milestones without overwhelming operational efficiency.
- Pristine ivory/bone surfaces (`#FBF9F7` and pure white containers) are embedded within the dark universe to preserve surgical readability for quotes, service selections, calendars, and guest registries.
- UI elements carry subtle golden halos, soft metallic borders, and generous breathing room, delivering a high-touch concierge digital experience.

## Colors

The color palette centers around a refined balance between nighttime depth and brushed metallic radiance.

### Core Roles & Tokens
- **Background Root (`#0A0A0C`):** Deep obsidian night with subtle warm undertones.
- **Surface Dark Canvas (`#141417`):** Elevated sidebar, dark card, and contextual modal containers.
- **Surface Light Stage (`#FBF9F7` / `#FFFFFF`):** High-contrast, clean working canvas utilized for dense interactive sheets, data entry forms, pricing calculators, and calendar selectors.
- **Primary Metallic (`#D4A373`):** Brushed rose gold / warm copper used for primary CTAs, active menu indicators, and highlighted dates.
- **Secondary Bronze (`#C58A68`):** Deep metallic tone for hover states, selected badges, and secondary buttons.
- **Tertiary Champagne Glow (`#E0A98B`):** Soft luminous highlight used for sparkles, active tabs, and gentle gradients.
- **Text On Dark:** Primary `#F5F3EF`, Muted `#9E9A95`.
- **Text On Light:** Primary `#1A1918`, Secondary `#64605C`, Muted `#9D9892`.
- **Functional Semantics:** 
  - Success / Confirmed: `#3D8260` (Deep emerald muted).
  - Warning / In Review: `#D4A373` (Rose gold amber).
  - Error: `#B84A4A` (Velvet crimson).

## Typography

The type scale balances the romantic, editorial distinction of **Playfair Display** with the clean geometric ergonomics of **Outfit**.

- **Playfair Display (Display & Headlines):** Infuses titles, milestone milestones, step headers, and event categories with haute couture authority and festive distinction.
- **Outfit (Body, Metadata & UI Controls):** Ensures maximum clarity across complex budgetary grids, customer forms, timeline selectors, and responsive navigation items.
- **Uppercase Tracking:** Section eyebrows, status chips, and table headers adopt `label-caps` with wide letter-spacing (`0.12em`) to mirror luxury house catalog styling.

## Layout & Spacing

This design system uses an integrated dual-frame architecture reflecting modern event back-office dashboards:

- **Desktop Structure:** 
  - Fixed-width dark navigation drawer (`260px`) anchored on the left.
  - Floating central light canvas module featuring generous inner padding (`2.5rem` / `space-2xl`) to handle transactional steps (Service pickers, Budget calculators, Multi-step client onboarding).
  - 12-column adaptive fluid sub-grid within the central sheet for component arrays (e.g., 2 or 3-column service cards, 4-column metrics).
- **Mobile Viewport (<768px):**
  - Collapsible header bar with gold monogram badge.
  - Full-bleed or softly rounded inset card stack with `1rem` screen margin.
  - Sticky bottom action dock housing primary CTAs (e.g., "Continuar", "Cadastrar Cliente") with frosted backdrop blur.
- **Spacing Rhythm:** Standardized on an 8pt base grid with 4pt micro-adjustments for fine luxury line breaks.

## Elevation & Depth

Visual hierarchy leverages dual-tone layering, atmospheric illumination, and delicate metallic trims:

1. **Base Layer (L0):** Dark background (`#0A0A0C`) textured with faint gold dust particles or radial ambient flares.
2. **Elevated Shell (L1):** Deep matte card surfaces (`#141417`) bounded by a subtle `1px` border of `rgba(212, 163, 115, 0.15)`.
3. **Primary Stage Layer (L2):** The crisp ivory content container (`#FBF9F7`) utilizing an expansive champagne ambient shadow:
   - `box-shadow: 0 20px 48px -8px rgba(0, 0, 0, 0.45), 0 0 24px -2px rgba(212, 163, 115, 0.08);`
4. **Interactive Cards & Modals (L3):** 
   - Light state: Subtle boundary line (`#ECE7E1`) with soft drop shadow `0 8px 24px rgba(0, 0, 0, 0.04)`. Hover transitions introduce a warm metallic glow `0 0 0 1.5px #D4A373`.
   - Floating action trays on mobile feature `backdrop-filter: blur(16px)` with `rgba(14, 14, 16, 0.85)`.

## Shapes

The geometric personality balances structured editorial confidence with softened, inviting curves:
- Standard buttons and text fields use `rounded-md` (`0.5rem` / `8px`) to maintain clean lines.
- Light interior working containers feature `rounded-2xl` (`1.25rem` / `20px` to `1.5rem` / `24px`), providing a comfortable tactile border against dark backdrops.
- Badges, status pills, and counter selectors utilize `rounded-full` (capsule profile) for smooth visual rhythm.

## Components

### Buttons
- **Primary Rose Gold Action:** Linear gradient (`linear-gradient(135deg, #D4A373 0%, #C58A68 100%)`) with white or dark espresso text (`#1F130B`), font weight 600, padding `12px 24px`, radius `8px`. Hover produces subtle illumination (`box-shadow: 0 4px 16px rgba(212, 163, 115, 0.35)`).
- **Secondary / Outline:** Background transparent, border `1px solid #D4A373`, text `#D4A373`.
- **Dark Action (Sub-controls):** Background `#1F1E22`, hover `#2A292E`, text `#F5F3EF`, subtle outline `rgba(255, 255, 255, 0.08)`.

### Form Fields & Inputs
- Set within light panels with an ivory fill (`#F5F2ED`), `1px solid #E5DFD7`, text `#1A1918`, placeholder `#9D9892`. Focus state shifts outline to `#D4A373` with a warm glow.
- When placed directly on dark surfaces, inputs take `#1A191E`, border `rgba(212, 163, 115, 0.25)`, text `#FBF9F7`.

### Service & Catalog Cards
- Light surface variant: Clean white container with `#EDE7DE` border. Includes minimalist champagne/rose-gold stroke icon, service title in `title-md`, price highlighted in bold bronze, and an explicit "+" or counter trigger.
- Dark mobile variant: `#161519` card surface with bronze icon container and high-contrast gold metadata.

### Data Tables & Budget Breakdowns
- Clean horizontal dividers (`#F0ECE4`).
- Monospaced or tabular figures for currency alignment (`R$`).
- Total / summary container wrapped in warm gradient accent with bold Playfair emphasis on final balances.

### Date & Timeline Pickers
- Mini calendar grid with active selection represented by a filled `#D4A373` circle and white typography. 
- Available dates carry subtle amber underlines; selected ranges utilize a soft champagne wash (`rgba(212, 163, 115, 0.15)`).

### Status Pills & Chips
- **Aprovado / Confirmado:** Subtle warm mint green tint with dark emerald text.
- **Em Análise / Aguardando:** Pale rose gold fill with `#8C5835` bronze text.
- **Em Andamento:** Light amber or warm metallic capsule.
